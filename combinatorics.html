Combinatorial algorithms

source code: https://github.com/qyrhx/Unranking-Algos

Overview

An academic project done with a mathematics professor at my university. The goal was to implement the algorithms from a research paper and visualize them. It was not as simple as implementing a web interface: the algorithms come first, with performance in mind from the start, and the UI sits on top of them.

Heavy computation behind a live UI

The computations are expensive, and running them on the main thread freezes the page. I moved them into Web Workers so calculation is isolated and the interface stays responsive. The visualization was a challenge of its own.

From TypeScript to SymPy

We then translated the algorithms from TypeScript to Python and contributed them to SymPy. That meant reading through the library and learning to write code that matches its style and design.

...

Reading a professional codebase like SymPy is one of the best ways to learn. Implementing a paper teaches you where the description ends and the engineering begins. Fun project, despite the paper making me pull my hair out at times
