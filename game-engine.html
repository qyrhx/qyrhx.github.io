e2d: 2D game engine

source code: github.com/qyrhx/e2d

Overview

A 2D game engine in C++ with graphics, collisions, input and animation.
To be honest, performance here was not a concern here...yes, the C++ mindset is always present, but not my main task. The questions were how the engine would be used, how to organize it internally, and how the parts fit together. It felt as much like planning and engineering as programming. I found myself writing less code and thinking quite a bit whether that approach works well with the rest of the system. It was an interesting experience.

Using the engine

The engine coordinates events, rendering, assets and how they are stored, animation and the map. Each concern lives in its own manager:

// Each spritesheet row is an animation state (Idle = 0, Walk = 1, ...)
          enum class PlayerAnimationState { Idle = 0, Walk = 1 };

          auto sheet  = engine.spritesheet_manager.load_spritesheet("file.png", {64, 64});
          auto player = engine.world_manager.new_character();
engine.spritesheet_manager.bind_spritesheet(player, sheet);
engine.spritesheet_manager.set_entity_animation_state(player, PlayerAnimationState::Walk);

engine.input_manager.bind(KeyEvent{.key = 'D', .ctrl = true}, [&] {
    engine.world_manager.get_character(player).move(-200, 0);
});

The core is done and features can be built on top of it. Once I have some time at my hand, I plan to continue developping it into something larger. Maybe audio is next, followed by more advanced features.
