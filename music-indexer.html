Music indexer

source code: github.com/qyrhx/midx

Overview

A Linux library that indexes music files. Given one or more directories, it finds music files, extracts their metadata and stores everything in an SQLite database. It is designed as the backend for a music player. Documentation is generated with Doxygen.

Designing a library

API design is what I found myself thinking about a good amount here, not performance, because here I am building a library not an app. I had to work out how I would want a music indexing library to look from the caller's side.

Python bindings

Another useful thing I learn is how to write python bindings for C++ library, I used pybind11, it was pretty interesting and fun!
