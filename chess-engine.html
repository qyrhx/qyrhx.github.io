Chess engine

source code: github.com/qyrhx/chess-engine

Overview

A chess engine written from scratch in C++20 around bitboards. It began as a way to think seriously about performance. PERFT testing is what made it more than a toy: counting the leaf nodes of the move tree to a fixed depth and comparing against known values means move generation is verifiably correct.

Bitboards

A board has 64 squares and a machine word has 64 bits, so a set of squares is just an integer. Move generation becomes shifts, masks and bit scans, and small tricks fall out of that fit. My favourite is a one-liner:

constexpr bool more_than_one(Bitboard b) { return b & (b - 1); }

b - 1 flips the lowest set bit and every zero below it, so b & (b - 1) clears the lowest set bit. The result is nonzero exactly when two or more bits were set. In chess that detects a double check, where only king moves are legal.

Learning from Stockfish

Reading Stockfish's code taught me a lot. Sometimes I imitated its approach, and other times I only read it to understand why it does something.

What I learned

Performance work needs measurement, and perft turns correctness into something you can check. Reading other people's engine code is a skill of its own.
